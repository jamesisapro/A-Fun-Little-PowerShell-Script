This is a PowerShell script that will launch tabs of Rick Astley's Never Gonna Give You Up
once every millisecond, causing your PC to crash, lag, or just cause general mayhem.
To try it out run the .ps1 script, or create a shortcut for pranks and general chaos. 
To properly create a shortcut that will run the .ps1 instead of opening it in notepad (a Windows safety feature), format your shortcut like this: 
"C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -ExecutionPolicy Bypass -File "C:\Users\yourusername\yourscript.ps1"
